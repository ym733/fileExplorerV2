# FileExplorerV2 (Work in Progress)

This Project is a web-based alternative for the popular tool [FileZilla](https://en.wikipedia.org/wiki/FileZilla). All a user has to do is to clone and run this repository on their remote server and the application should allow them to browse and make edits to all the files on their server as if they were on their local machine. This is still a work in progress
